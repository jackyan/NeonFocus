## 一、产品概述

### 1.1 产品定位

**NeonFocus** 是一款集"视觉美学"与"听觉氛围"于一体的专注时钟应用，通过科技美学设计和沉浸式音景，为用户创造理想的专注空间。

**核心价值主张**：
> 不只是看时间，而是进入一个完整的专注空间

**一句话描述**：
> 赛博美学时钟 + 环境音景 + 专注工具 = 你的数字禅修空间

### 1.2 目标用户

**核心用户画像**：

| 用户群体 | 特征 | 痛点 | 占比 |
|---------|------|------|------|
| 数码美学爱好者 | 追求桌面搭配、热爱科技产品 | 现有时钟App视觉单调 | 30% |
| 生产力工具用户 | 需要番茄钟、专注工具 | 工具功能分散，切换麻烦 | 40% |
| 赛博朋克爱好者 | 喜欢科幻、电子、未来感 | 缺乏符合审美的应用 | 15% |
| ASMR/白噪音用户 | 需要背景音助眠/专注 | 音频App缺少视觉设计 | 15% |

**用户场景**：
```
场景1：学习专注
├─ 时间：工作日晚上8-11点
├─ 地点：书桌前
├─ 需求：番茄钟计时 + 背景音乐 + 视觉陪伴
└─ 期望：沉浸式专注体验

场景2：桌面装饰
├─ 时间：全天
├─ 地点：工作台、床头柜
├─ 需求：美观的时钟显示 + 充电屏保
└─ 期望：提升空间美学

场景3：冥想放松
├─ 时间：睡前、午休
├─ 地点：床上、沙发
├─ 需求：舒缓的视觉 + 放松音景
└─ 期望：帮助入眠或放松

场景4：健身计时
├─ 时间：运动时段
├─ 地点：健身房、家中
├─ 需求：大字体计时 + 间歇提醒
└─ 期望：清晰可见、操作简单
```

### 1.3 竞品分析

| 产品 | 优势 | 劣势 | 我们的差异化 |
|------|------|------|-------------|
| Zen Flip Clock | 极简美观、翻页动画经典 | 功能单一、无音频 | ✓ 视听结合<br>✓ 多风格主题<br>✓ 重力交互 |

### 3.2 交互设计规范

#### 手势定义

```
全局手势：
├─ 左滑（Swipe Left）
│   └─ 触发条件：水平滑动距离 > 100px，速度 > 300px/s
│   └─ 动作：切换到番茄钟页面
│   └─ 反馈：触觉震动（轻）
│
├─ 右滑（Swipe Right）
│   └─ 触发条件：同上
│   └─ 动作：切换到秒表页面
│   └─ 反馈：触觉震动（轻）
│
├─ 上滑（Swipe Up）
│   └─ 触发条件：垂直滑动距离 > 150px，速度 > 400px/s
│   └─ 动作：打开主题选择器
│   └─ 反馈：触觉震动（中）
│
├─ 下滑（Swipe Down）
│   └─ 触发条件：同上
│   └─ 动作：关闭当前弹窗
│   └─ 反馈：无
│
├─ 单击（Tap）
│   └─ 触发条件：快速点击
│   └─ 动作：显示/隐藏设置按钮
│   └─ 反馈：触觉震动（轻）
│
├─ 长按（Long Press）
│   └─ 触发条件：按住1.5秒
│   └─ 动作：快速重置计时器
│   └─ 反馈：触觉震动（重）+ 确认对话框
│
└─ 双击（Double Tap）
    └─ 触发条件：0.3秒内点击两次
    └─ 动作：切换亮度模式（正常/暗/极暗）
    └─ 反馈：触觉震动（中）
```

#### 重力感应规范

```dart
class GravityInteraction {
  // 判定阈值
  static const double faceDownThreshold = -8.0;  // m/s²
  static const double faceUpThreshold = 8.0;
  
  // 持续时间（防误触）
  static const Duration holdDuration = Duration(seconds: 2);
  
  // 灵敏度等级
  enum Sensitivity {
    high(6.0),    // 灵敏
    medium(8.0),  // 标准
    low(10.0);    // 迟钝
    
    final double threshold;
    const Sensitivity(this.threshold);
  }
  
  // 使用逻辑
  void onAccelerometerData(AccelerometerEvent event) {
    if (event.z < -Sensitivity.medium.threshold) {
      // 屏幕朝下持续2秒 → 开始专注
      startFocusModeWithDelay();
    } else if (event.z > Sensitivity.medium.threshold) {
      // 屏幕朝上 → 暂停并询问
      pauseAndShowDialog();
    }
  }
}

### 4.2 核心使用流程

#### 流程1：使用番茄钟专注

```
用户操作                        系统反应
────────────────────────────────────────────────
1. 左滑屏幕                    → 切换到番茄钟页面
                                 播放切换音效

2. 旋转虚拟旋钮                → 实时显示时长
                                 每5分钟触觉反馈

3. 选择音景                    → 显示音景选择器
   点击"雨声"                    播放预览

4. 扣手机屏幕朝下              → 倒计时2秒后
                                 开始计时
                                 降低屏幕亮度
                                 开始播放音景

5. [25分钟后]                  → 振动提醒
                                 播放完成音效
                                 弹出完成对话框

6. 选择"开始休息"              → 切换为休息倒计时
                                 音景切换为放松音
```

#### 流程2：充电床头时钟

```
用户操作                        系统反应
────────────────────────────────────────────────
1. 插入充电器                  → [Android] 自动启动App
                                [iOS] 需要快捷指令配置

2. 检测环境光                  → 深夜(23:00-06:00)
                                 自动切换红光主题
                                 降低亮度到10%

3. 显示充电信息                → 在时钟下方显示
                                 "⚡ 85% · 剩余1小时"

4. 防烧屏保护                  → 每5分钟偏移2-3像素
                                 每30分钟旋转0.5度

5. 拔出充电器                  → 恢复正常亮度
                                 恢复原主题
```

```

```

        ↓
    提供按钮：

```

    弹出提示

### 9.2 术语表

```
辉光效果（Glow Effect）：
└─ 模拟电子管/霓虹灯的发光效果，通过多层模糊实现

番茄钟（Pomodoro Technique）：
└─ 25分钟工作+5分钟休息的时间管理法

音景（Ambience/Soundscape）：
└─ 环境背景音，如雨声、咖啡馆声音等

重力感应（Gravity Interaction）：
└─ 利用加速度传感器检测手机姿态

防烧屏（Burn-in Protection）：
└─ 防止OLED屏幕长期显示静态图案造成永久损伤

Shader（着色器）：
└─ GPU编程，用于实现复杂的视觉效果

Widget（小组件）：
└─ iOS/Android主屏幕或锁屏上的小部件

ARPU（Average Revenue Per User）：
└─ 单用户平均收入

LTV（Lifetime Value）：
└─ 用户生命周期价值

CAC（Customer Acquisition Cost）：
└─ 用户获取成本
```
